# Security & Safety Policy

## Supported Versions

Only the latest commit on the `main` branch is actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| legacy  | :x:                |

## Reporting Safety & Functional Issues

This is an open-source 3D CAD parametric project designed for custom benchtop power supplies. 

While it is not compiled executable software, physical clearances, component tolerances, and insulation distances are critical when handling mains voltage (**IEC C14**) or high-current DC inputs (**XT60, Anderson Powerpole**).

If you identify a geometric interference, clearance issue, or code bug that could cause physical hazards, short circuits, or compromise user safety:
1. Open an issue on GitHub detailing the exact coordinates, module types, and clearance problem.
2. For severe safety-related flaws, you may open a [Private Vulnerability Report](https://github.com/camiu01/YAPBPS/security/advisories/new) via the Security tab.
